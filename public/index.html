Create alert

      

        
        
        
        
        
Alerts are checked against live prices while Wickline is open in a tab. You'll get a sound, an on-screen message and, if you allow it, a desktop notification.

        

      

    

  


  

    

      
Publish to the community

      

        
Your script will be listed in every Wickline app's Community tab, where anyone can add it to a chart with one click.

        
        
        
        
        
Next, GitHub opens with everything filled in: press Submit new issue (a free GitHub account is needed). A quick check runs your script, and it shows up in the Community tab a few minutes later. To update it later, edit that GitHub issue.
